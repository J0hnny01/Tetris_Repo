## Libreria Grafica Utilizada
Toda la interfaz grafica, manejo de ventanas y captura de eventos del teclado fue implementada utilizando **SFML (Simple and Fast Multimedia Library)**. 
Especificamente, se requiere enlazar los siguientes modulos basicos de SFML 2.x:
* `sfml-graphics`
* `sfml-window`
* `sfml-system`
El proyecto esta configurado nativamente para este IDE.
1. Abre el archivo de proyecto `MiProyecto.zpr` en el editor Zinjai.
2. Verifica en Opciones -> Ejecucion que las opciones de enlazado incluyan las librerias de SFML mencionadas.
3. Ve al menu superior y haz clic en **Ejecucion -> Compilar y Ejecutar** (o simplemente presiona la tecla `F9`).
4. Zinjai compilara todos los archivos `.cpp` del arbol y lanzara la ventana grafica automaticamente.
